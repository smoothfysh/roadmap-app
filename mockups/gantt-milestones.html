Diamond is vertically centred inside the bar at its date, with a white halo so it stays legible on any of the five pastel fills. Hollow = still ahead, solid = date passed. The popover is drawn in a page-level overlay, not inside the chart — the Gantt body is an overflow-x:auto scroller, so anything drawn in it gets clipped. It flips below the bar when there's no room above, and closes on scroll, outside click or Esc. Read-only; editing happens in the modal.

Two things worth a look before I build it. (1) Hit Compact — the two September milestones on Listing quality score are 7 days apart, under 14px at compact width, so the later one nudges right to stay clickable. (2) Centring the diamond inside the bar costs label text — I clip the label short of the leftmost diamond so a marker never sits on top of a word, which leaves Semantic search rollout reading as "Semanti..". Toggle Top edge above to see the same chart with the diamonds straddling the bar's top edge instead: every label survives intact, at the cost of a slightly taller row and a looser tie to the bar. 3 — What this implies in code

Data model — one new field per item

// item.milestones — null when unused
[
  { id: "ms-1a2b",
    date: "2026-09-15",
    label: "Model v2 signed off" },
  …
]

Sorted by date on write, so every reader can trust the order.

Rendering rules

  • Position from the same day→x mapping the bars use, so a diamond can't drift from its bar.
  • A milestone outside the item's start/end range is clamped to the nearest bar edge and flagged in the popover.
  • Nudge-apart: minimum 14px between centres, applied left→right after sorting.
  • Popover lives in a fixed-position overlay — drawing it inside the Gantt body means overflow-x:auto clips it.
  • Row height goes 34px → 36px only if we pick the top-edge placement.
  • Collapsed lanes stay plain — no diamonds on the muted band.
  • Gantt only. Cards in the other three views are unchanged.
  • Read-only previews keep diamonds and popovers; the modal's inputs go disabled.

⚠ Touches the "do not break" list

  • Sharing — milestones rides inside the item objects in encodeShareData. Deflate handles it; a 40-item roadmap with a few milestones each adds roughly 100–200 chars to the link.
  • Saving — backup JSON picks it up for free; handleBackupImport needs the field defaulted to null for older files.
  • CSV — new milestones header holding a JSON string, exactly the pattern enables already uses at App.jsx:175.
